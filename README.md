# La Cave de Pépé

Application web de gestion pour un commerce de sodabi.

## Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Supabase
* Vitest
* Vercel

## Fonctionnalités

* Gestion des ventes : Si, Ka, Demi et Litre
* Suivi du stock en temps réel
* Entrées et ajustements de stock
* Gestion des bonus
* Gestion des clients
* Crédits et paiements partiels
* Historique des opérations
* Tableau de bord et statistiques
* Authentification et gestion des utilisateurs
* Synchronisation des données via Supabase
